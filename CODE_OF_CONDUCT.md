# Code of conduct

Vengeance adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)
as its code of conduct. It applies to everyone who takes part in the project: in issues, pull
requests, reviews, discussions and any other project space.

In short: be respectful, assume good faith, keep criticism about the work rather than the person,
and leave room for people who are new to the project.

## Reporting

The project has no private email address for conduct reports. GitHub's own tools are the private
routes:

- For a comment, issue, pull request or discussion, open its **...** menu, choose
  **Report content**, and report it to the repository maintainers. The report reaches the
  maintainer, @LuciferMornens, without being made public.
- For a person, use **Block or report** on their GitHub profile. That report goes to GitHub.

Don't put details you want kept private in a public issue or mention. The maintainer handles
reports confidentially and decides on any action, following the enforcement guidance in the
Contributor Covenant.
